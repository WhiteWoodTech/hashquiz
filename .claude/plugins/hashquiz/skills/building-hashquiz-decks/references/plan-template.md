# Quiz Plan Template

Use this template when generating `plan.md` for a quiz deck.

## Template

```markdown
# {Quiz Title} — Plan

**Target questions:** {number}
**Estimated duration:** {total timer sum} seconds (~{minutes} min)
**Language:** {language}
**Difficulty mix:** {X}% easy, {Y}% medium, {Z}% hard
**Question types:** {single, multiple, or mix}

---

## Sources Used

- {source filename 1} — {brief description of what it covers}
- {source filename 2} — {brief description}
- {Web research} — {topic searched, if applicable}

---

## Difficulty Distribution

| Difficulty | Count | Percentage |
|------------|-------|------------|
| easy       | {n}   | {x}%       |
| medium     | {n}   | {y}%       |
| hard       | {n}   | {z}%       |

---

## Tag Coverage

| Tag | Questions |
|-----|-----------|
| {tag1} | Q1, Q3, Q5 |
| {tag2} | Q2, Q4 |

---

## Questions

### Q1 — {Short question summary}

- **Type:** single | multiple
- **Difficulty:** easy | medium | hard
- **Timer:** {seconds}s
- **Tags:** [{tag1}, {tag2}]
- **Source:** {which source document or web research}
- **Key concept:** {what this question tests}
- **Notes:** {any special considerations for answer design}

### Q2 — {Short question summary}

...

---

## Review Checklist

- [ ] Questions cover all key topics from sources
- [ ] Difficulty distribution matches target
- [ ] No duplicate or overly similar questions
- [ ] Tags are consistent and meaningful
- [ ] Timer values are realistic for question complexity
- [ ] Mix of single and multiple choice (if requested)

---

_Plan created: {date}_
_Ready for quiz generation: [ ]_
```

## Guidelines for Plan Creation

1. **Read sources thoroughly** before planning questions
2. **Distribute topics evenly** across the source material
3. **Vary question styles**: definitional, comparative, applied, scenario-based
4. **Easy questions** should test recall of key facts
5. **Medium questions** should test understanding and application
6. **Hard questions** should test analysis, comparison, or edge cases
7. **Each question summary** should be specific enough to generate from without ambiguity
8. **Tag questions** using both quiz-level tags and question-specific tags
9. **Timer values**: 15-20s for easy, 20-25s for medium, 25-35s for hard
